Windows 下从零开始安装 Hexo 教程

2026-05-02
| Edit page

Hexo 是一个快速、简洁且高效的博客框架，基于 Node.js 开发。本文将详细介绍在 Windows 系统上从零开始安装 Hexo 的完整步骤。

一、环境准备

1.1 安装 Node.js

Hexo 依赖 Node.js 运行环境，首先需要安装 Node.js。

  1. 访问 Node.js 官网

  2. 下载 LTS（长期支持版） 安装包（推荐）

  3. 双击安装包，按照向导完成安装（全部默认选项即可）

验证安装： 打开命令提示符（Win+R，输入 cmd），输入以下命令：

node -v
npm -v

如果显示版本号，说明安装成功。

1.2 安装 Git

Git 用于版本管理和部署博客。

  1. 访问 Git 官网

  2. 下载 Windows 版本安装包

  3. 安装时保持默认选项，建议勾选 “Git Bash Here” 选项

验证安装：

git --version

二、安装 Hexo

2.1 使用 npm 全局安装 Hexo

打开命令提示符（建议以管理员身份运行），执行：

npm install hexo-cli -g

注意： 如果安装速度慢，可以配置阿里云镜像：

npm config set registry http://registry.npmmirror.com

2.2 验证 Hexo 安装

hexo version

如果显示 Hexo 版本信息，说明安装成功。

三、创建博客项目

3.1 初始化博客

选择一个存放博客的目录（例如 D:\Blog），在命令提示符中执行：

hexo init myblog
cd myblog
npm install

参数说明：

  • myblog 是博客文件夹名称，可以自定义

  • npm install 会安装项目依赖

3.2 启动本地服务器

hexo server

或简写：

hexo s

启动后，打开浏览器访问 http://localhost:4000，即可看到默认的 Hexo 博客页面。

四、基本配置

4.1 修改站点配置

打开博客根目录下的 _config.yml 文件，修改基本信息：

# 站点信息
title: 我的博客
subtitle: 记录生活与技术
description: 一个分享知识的个人博客
author: Your Name
language: zh-CN
timezone: Asia/Shanghai

# URL 设置
url: http://yourdomain.com
root: /

4.2 安装主题（可选）

Hexo 支持多种主题，以安装流行的 Next 主题为例：

git clone https://github.com/theme-next/hexo-theme-next themes/next

然后在 _config.yml 中修改主题：

theme: next

五、常用命令

命令功能
hexo new "文章标题"创建新文章
hexo generate生成静态文件
hexo server启动本地服务器
hexo deploy部署到远程服务器
hexo clean清除缓存文件

六、常见问题解决

6.1 安装速度慢

使用阿里云镜像：

npm config set registry http://registry.npmmirror.com

6.2 端口被占用

修改端口号：

hexo server -p 5000

6.3 命令找不到

检查环境变量是否包含 Node.js 和 npm 的安装路径。

七、部署到 GitHub Pages（可选）

  1. 在 GitHub 创建仓库：username.github.io

  2. 安装部署插件：

npm install hexo-deployer-git --save
  1. 修改 _config.yml：
deploy:
  type: git
  repo: https://github.com/username/username.github.io.git
  branch: main
  1. 部署：
hexo deploy

总结

通过以上步骤，你已经在 Windows 系统上成功安装了 Hexo 并创建了第一个博客项目。接下来可以开始撰写文章、自定义主题，打造属于自己的个人博客。遇到问题可以查阅 Hexo 官方文档 获取更多帮助。
